## 📖 Introduction / 简介

**Parallax Neuralink** is a Chrome Extension that gamifies the experience of running local AI models via the [Parallax](https://github.com/FluxML/Parallax) distributed network. Instead of a boring terminal, you interact with a cyberpunk interface where every interaction (chat, summarization) earns you "Computing Power" (Score).

**The more nodes you connect, the higher your score multiplier!**

**Parallax Neuralink** 是一个 Chrome 扩展程序，它将通过 [Parallax](https://github.com/FluxML/Parallax) 分布式网络运行本地 AI 模型的体验进行了“游戏化”包装。告别枯燥的终端，你将在一个赛博朋克风格的界面中与 AI 交互。每一次对话、每一次网页总结，都会为你赚取“算力”（分数）。

**接入的计算节点越多，你的得分倍率就越高！**

## ✨ Features / 核心功能

### 1. Distributed Node Link & Multiplier (分布式节点链接与倍率)
- **Real-time Topology**: Automatically detects the number of nodes connected to your Parallax network.
- **Score Multiplier**: Every connected node grants a **+1.0x** multiplier to all your score gains. 2 Nodes = 3x Score!
- **实时拓扑识别**：自动检测 Parallax 网络中接入的节点数量。
- **算力倍率系统**：每一个接入的节点都会提供 **+1.0x** 的全局算力加成。双机组网，收益翻倍！

### 2. Data Absorption (数据吞噬)
- **One-Click Summarize**: Click "Absorb" on any webpage to feed its content to your local LLM.
- **Smart Summary**: Get a concise summary of the page content while earning massive points based on the data volume.
- **一键吞噬**：在任意网页点击“Absorb”，将页面内容“喂”给本地大模型。
- **智能总结**：获取网页内容的精准摘要，并根据数据量获得巨额算力经验值。

### 3. Gamified Progression (游戏化进程)
- **Cyberpunk UI**: Immersive visual feedback with animations and sound effects (visual only for now).
- **Achievements**: Unlock titles like "Silicon Miner", "Quantum Architect", and "Dimension Ascension".
- **赛博 UI**：沉浸式的视觉反馈。
- **成就系统**：解锁“硅基矿工”、“量子架构师”、“维度飞升”等头衔，并获得永久属性加成。

## 🛠️ Installation / 安装指南

1. **Prerequisites / 前置要求**:
   - Ensure [Parallax](https://parallax.loc) is running locally (Default port: `3001` or compatible `11434` API).
   - 确保本地已启动 Parallax 服务（默认端口 `3001` 或兼容的 `11434` 接口）。

2. **Load Extension / 加载插件**:
   - Clone this repository: `git clone https://github.com/yourusername/ParallaxNeuralink.git`
   - Open Chrome and go to `chrome://extensions/`.
   - Enable **Developer mode** (top right).
   - Click **Load unpacked** and select the project folder.
   - 克隆本仓库。
   - 打开 Chrome 进入 `chrome://extensions/`。
   - 开启右上角的 **开发者模式**。
   - 点击 **加载已解压的扩展程序**，选择本项目文件夹。

## 🎮 Usage / 使用方法

1. Click the extension icon to open the side panel.
2. **Check Status**: Ensure the status bar says "分布式网络在线" (Distributed Network Online). The node count will be synced automatically.
3. **Chat**: Type in the chat box to talk to your local model.
4. **Absorb**: Navigate to a content-rich webpage and click "Smart Summarize" (智能总结) to gain points.
5. **Level Up**: Check the "Achievements" tab to see your progress!

1. 点击插件图标打开侧边栏。
2. **检查状态**：确保顶部状态栏显示“分布式网络在线”。节点数量会自动同步。
3. **对话**：在聊天框输入内容与本地模型交互。
4. **吞噬数据**：浏览任意内容丰富的网页，点击“智能总结”获取算力。
5. **升级**：在“成就”标签页查看你的飞升进度！
